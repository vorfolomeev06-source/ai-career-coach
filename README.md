# AI Career Coach

## About the Project

AI Career Coach is my individual project that I built during the Ironhack AI Engineering Bootcamp.

I wanted to create a simple website that helps people prepare for job interviews, improve their CVs, and understand which skills they need for a specific job.

The application uses AI to provide personalized feedback and career advice.

## Main Features

- **Mock Interview:** An AI interviewer asks 7 questions based on the chosen job role and gives a final score with feedback.
- **CV Reviewer:** Analyzes a CV from a PDF file or text and suggests improvements.
- **Job Fit:** Compares a CV with a job description and identifies matching and missing skills.
- **Learning Roadmap:** Creates a personalized 4-week learning plan based on missing skills.

## Technologies

I used Python, FastAPI, Pydantic, and the OpenAI API for the backend, and HTML, CSS, and JavaScript for the frontend.

## What I Learned

This project helped me understand how to build a complete AI application, connect the frontend to the backend, work with APIs, and use structured AI outputs.

The biggest challenge was connecting all the different features and making them work together in one application.

I also added basic prompt injection protection and tested the four main features.
